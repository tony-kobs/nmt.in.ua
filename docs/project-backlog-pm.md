# Беклог nmt.in.ua — звіт для PM

**Продукт:** [nmt.in.ua](https://nmt.in.ua) — тренажер підготовки до НМТ з математики  
**Репозиторій:** [tony-kobs/nmt.in.ua](https://github.com/tony-kobs/nmt.in.ua)  
**Період:** 25 серпня 2026 — 5 вересня 2026 (12 днів)  
**Обсяг:** 40 PR, 7 авторів комітів  
**Процес:** `feature/…` → PR у `dev` → реліз `dev` → `main`

---

## Коротко: де ми зараз

Гість бачить лендінг → реєструється або логіниться → проходить тест за темою, Ultimate або симулятор НМТ → бачить відсоток і рекомендації → авто-сесії з’являються в історії. Викладач призначає сесії. Адмін імпортує контент.

**Стек:** Next.js 16, TypeScript, CSS Modules, MySQL, next-intl (українська / англійська / німецька).

**Ще не зроблено:** задачник (`/problems`) і консультації (`/consultations`).  
Операційно: навчальні матеріали вже на проді (`main`), але ще не підтягнуті в робочу гілку `dev`.
