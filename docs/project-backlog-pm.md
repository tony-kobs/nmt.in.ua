# Беклог nmt.in.ua — звіт для PM

**Продукт:** [nmt.in.ua](https://nmt.in.ua) — тренажер підготовки до НМТ з математики  
**Репозиторій:** [tony-kobs/nmt.in.ua](https://github.com/tony-kobs/nmt.in.ua)  
**Період:** 25 серпня 2026 — 5 вересня 2026 (12 днів)  
**Обсяг:** 40 PR, 7 авторів комітів  
**Процес:** `feature/…` → PR у `dev` → реліз `dev` → `main`

---

## Коротко: де ми зараз

Гість бачить лендінг → реєструється або логіниться → проходить тест за темою / симулятор НМТ / підручник → бачить відсоток і рекомендації → авто-сесії з’являються в історії. Викладач призначає сесії. Адмін імпортує контент.

**Стек:** Next.js 16, TypeScript, CSS Modules, MySQL, next-intl (українська / англійська / німецька).

**Ще відкрито (10.09):** якість банку `quiz_tasks` (6.5), порожні розділи підручника. Консультації: заявка учня + черга для всіх викладачів.  
Операційно: `dev` і `main` зрівняні; матеріали / підручник / задачник / симулятор варіантів — у коді.

## Що вміє продукт зараз

| Поверхня | Що вміє | Де |
| --- | --- | --- |
| Вітальна | Лендінг: герой, можливості, кроки, питання-відповіді, заклик до дії; три мови | `/`, `/welcome` |
| Вхід / реєстрація | Учень реєструється; сесія в cookie | `/login`, `/register` |
| Тест за темою | Тема + кількість завдань (видно банк), миттєвий розбір | `/` → `/session/[id]` |
| Симулятор НМТ | Офіційні варіанти 2022–2026, таймер, розбір помилок | `/simulator` |
| Підручник | Теорія за темами (`?topic=`), порожні розділи лишаються «готується» | `/materials/textbook` |
| Результати | Прогрес по темах + рекомендації «що далі» | `/results` |
| Сесії | Історія, авто-план, сесії від викладача | `/sessions` |
| Задачник | Друкований тест по темі | `/problems` |
| Консультації | Учень надсилає запит; викладачі/адміни бачать усі й закривають | `/consultations` |
| Імпорт | CSV або JSON, лише адмін | `/settings` |
| Ментор | Призначити заплановану сесію учню | `/sessions` + admin API |
