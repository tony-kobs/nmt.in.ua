## 1. Проблематика

Учні готуються до НМТ хаотично, без системи, часто не розуміють власних прогалин. Викладачам складно відстежувати прогрес кожного учня та давати персональні рекомендації.

## 2. Бачення продукту (scope)

Нижче — цільове бачення з картки Goldener Rechner. Це не список того, що вже збудовано. Фактичний MVP зіставлено в розділі 8.

### 2.1. Основний функціонал для учня

- Банк завдань за форматом НМТ: вибір відповіді, відповідність, коротка відповідь, розгорнутий розв’язок.
- Вибір теми / розділу програми (алгебра, геометрія, стереометрія, функції тощо), класу (5–11) і рівня складності.
- Генерація варіантів: випадковий підбір за темою, кількістю, складністю.
- Довідковий модуль: формули, теореми, приклади розв’язань за темами.
- Введення розв’язань без автопідказок (текстове поле або формульний редактор для ходу розв’язання, не лише фінальної відповіді).
- AI-перевірка: аналіз ходу міркувань, помилки в обчисленнях / методі, коментарі щодо оформлення.
- Історія спроб і прогрес: графік динаміки за темами, виявлення слабких місць.
- Режим іспиту з таймером (імітація реального НМТ, кількість завдань і час за форматом).
- Адаптивне тренування: підбір завдань на основі виявлених прогалин.

### 2.2. Модуль для викладача / репетитора

- Перегляд робіт учнів, коментарі.
- Статистика по групі / класу (типові помилки, середній прогрес).
- Створення власних варіантів / добірок для учнів.
- Спільний доступ через посилання або інтеграція з LMS.

### 2.3. Технічні та сервісні функції

- Збереження та експорт розв’язань / варіантів у PDF.
- Діагностичний тест на старті для визначення початкового рівня.
- Інтерфейс українською (з елементами для батьків / викладачів).
- Мобільна версія (PWA): учні часто тренуються зі смартфона або планшета.

### 2.4. Поза першим релізом (out of scope)

- Підготовка до НМТ з інших предметів.
- Відеоуроки.
- Перевірка рукописних розв’язань з фото.
- Чат-підтримка з викладачем.
- Гейміфікація (бейджі, рівні, XP).

## 3. Стейкхолдери, метрики, ризики

### 3.1. Стейкхолдери

- Учні 9–11 класів.
- Репетитори та шкільні вчителі.
- Батьки (як покупці підписки, якщо така запланована).
- Освітні центри / школи.

### 3.2. Метрики MVP

- Середній час на розв’язання завдань зменшується на 20%.
- Учні проходять симуляцію НМТ мінімум 3 рази.
- 70% користувачів повертаються до тренувань протягом тижня.
- Викладачі активно використовують модуль груп.

Станом на 5 вересня модуль груп ще не збудований, тож остання метрика стосується наступної версії, не поточного MVP.

### 3.3. Ризики

- Зміни у форматі НМТ.
- Недостатній банк якісних завдань.
- Висока конкуренція серед освітніх платформ.
- Потреба в точних математичних поясненнях (якість контенту критична).

## 11. Висновок для демо

За 12+ днів команда закрила робочий беклог першого релізу: імпорт, тест за темою, симулятор НМТ (варіанти), рекомендації, ролі, реєстрація, лендінг, три мови, підручник, задачник, діагностика, відгук.

Не закривати як «весь продукт готовий». Бачення Goldener Rechner ширше: інші типи завдань НМТ, хід розв’язання, AI-перевірка, групи викладача, PDF, повноцінний PWA. Це наступні версії.

Для демо 5 вересня показуємо: лендінг → реєстрація / вхід → тест або симулятор → результати з порадами → сесія, призначена викладачем → матеріали з формулами.
